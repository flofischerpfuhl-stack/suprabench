Run learnings

  • Separate harnesses before comparing agent scores.
  • Preserve exact max, high, and xhigh identities; generic rows are not interchangeable.
  • Use visible DeepSWE Best rows, not hidden JSON precision.
  • Keep curation batches bounded and defer otherwise valid rows once the cap is reached.
