Webhooks Planned — Scale tier

Subscribe to SupraBench data events — new score submissions, ranking shifts, content flags — and have us POST signed JSON payloads to your endpoint instead of polling.

Last updated: April 18, 2026 Reading time: 3 min
Status: design preview. Webhooks ship with the API GA on the Scale tier; this page documents the planned contract so you can architect against it now. Endpoint URLs and signature scheme may change before GA — watch the changelog.

Status

Not yet available. Scale-tier subscribers will be able to register a webhook URL from the dashboard at GA.

Planned events

EventWhen fired
submission.createdA user submits a new score (subject to quality validation).
submission.validatedSubmission's vote balance crossed into upvotes > downvotes; now counts toward rankings.
submission.invalidatedSubmission's vote balance flipped negative; removed from rankings.
model.ranking_changedA model's supraScore moved by > 1.0 in the last refresh cycle.
model.hiddenA model was hidden by community flag or admin action.
bench.createdA new benchmark was added.
bench.quality_changedA benchmark's quality score moved by > 5.

Delivery model

  • Method: HTTPS POST to your registered URL.
  • Body: JSON envelope with id, type, createdAt, data.
  • Retries: exponential backoff for 24 hours on non-2xx (1 min, 5 min, 30 min, 2 h, 6 h, 24 h).
  • Idempotency: events have stable id values; treat repeats as no-ops.
  • Ordering: not guaranteed. Always check createdAt against your last-processed timestamp.
  • Timeout: we wait 10 seconds for your response before treating it as a failure.

Signature verification

Every payload will include X-SupraBench-Signature, computed as:

X-SupraBench-Signature: t=<unix-ts>, v1=<hex(hmac-sha256(secret, t + "." + body))>

Verify by recomputing with your endpoint secret (issued at registration time) and rejecting if mismatch or if t is more than 5 minutes in the past (replay-attack defence).

Timeline

  • Now — design open for feedback. Open an issue if a planned event won't fit your use case.
  • API GA + 30 days — webhooks beta opens on Scale tier.
  • API GA + 90 days — webhooks marked GA, SLA applies.
